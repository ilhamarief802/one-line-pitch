One sentence, at most 240 characters, persuading a friend who has never coded to let an AI agent build their first app idea on make.fun. The sentence is the whole entry: it lives in `pitch.txt`, and `main.ts` hands it to the gate at `/output/entry.txt`.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
